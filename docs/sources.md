# Gadget data sources

이 프로젝트는 도구 이름·별칭·등장 매체를 여러 출처에서 교차 확인합니다.

## Primary working sources

1. Doraemon Wiki — Gadgets category
   - https://doraemon.fandom.com/wiki/Category:Gadgets
   - 전체 도구 탐색용.

2. Doraemon Wiki — Manga gadgets
   - https://doraemon.fandom.com/wiki/Category:Gadgets_from_the_original_manga
   - 원작 만화 우선 수집용.

3. もしも道具 — ひみつ道具一覧
   - https://moshimodogu.com/indexes/ichiran
   - 일본어 정식/별칭 대조용.

4. Yobubble/doraemon-gadgets-search-engine
   - https://github.com/Yobubble/doraemon-gadgets-search-engine
   - 영어명·일본어명·등장작 포인터를 확인하는 보조 데이터셋.

## Collection rules

- 외부 사이트의 장문 설명은 그대로 복사하지 않는다.
- `summary`는 프로젝트용으로 짧게 새로 작성한다.
- 이름이 다른 동일 도구는 `aliases`로 병합한다.
- 기능이 실질적으로 다른 변형은 별도 항목으로 유지한다.
- 원작/1979 애니/2005 애니/극장판/게임/스핀오프를 구분한다.
- 출처가 충돌하면 일본어 원전 계열과 최초 등장 정보를 우선 검토한다.
- 구현 가능도는 수집 단계에서는 비워 두고 별도 공학 검토 후 A~E로 평가한다.
